# UFC Fight Predictor

A simple dark mode website to predict UFC fight outcomes using a Gradio API.

## How to use

1.  Open the website.
2.  Enter the names of two UFC fighters.
3.  Click the "Predict Winner" button.
4.  The prediction will be displayed below the button.

## How to deploy

This project is set up for deployment to GitHub Pages.

1.  Push your code to the `main` branch of your GitHub repository.
2.  Run the following command in your terminal:

    ```bash
    npm run deploy
    ```

3.  The website will be deployed to `https://<your-username>.github.io/<your-repo-name>`.

For this project, the URL is [https://DKeAlvaro.github.io/ufc-predictions](https://DKeAlvaro.github.io/ufc-predictions).
